This is a tutorial to build an apptainer container.

1 - Launch an interactive job on Meluxina and Load Apptainer
You have to have access to the software Apptainer. On MeluXina, it is only accessible from the nodes.
Very first step is to connect to a node with the following commands:
    - To launch an interactive job:
$ salloc -A COMPUTE_ACCOUNT -t 01:00:00 -p gpu -q short -N 1 -G 4
# Note : Replace COMPUTE_ACCOUNT by our account identification number (p*****) 
    - To load the Apptainer module:
$ module load Apptainer/1.2.4-GCCcore-12.3.0


2 - Launch the building of the environment
To launch the build operation you have to execute the following line (from the root of your project).

$ apptainer build container.sif container.def

Note : This operation might take a while (5 to 10min)


3 - Mount the dataset into the built container
Now that your container is build you can mount your dataset on it. To do so, you have to add to your .bashrc the following command line :
        export APPTAINER_BINDPATH="/PATH/TO/DATASET/ON/MELUXINA:/PATH/TO/DATASET/ON/CONTAINER

example :
    ($ export APPTAINER_BINDPATH="/project/home/p200177/DE_371/datasets:/project/home/p200177/DE_371")

4 - Final check
You can now open a shell on the container and check that the directory is mounted.

To do so, execute the following commands : 
$ apptainer shell container.sif
